Red outlines are matched CSV areas. Optional Show all detected outlines adds every green path found on the named PDF (can look like extra boxes — leave off for a clean view). Click a red room to edit its name. With Fit / Increase / Decrease on, you can drag / scale the whole overlay or drag a red-box edge. Uncheck it to lock the current floor plan in place, then only Add area or Copy / Paste (drag the copy, release to drop; Ctrl+C / Ctrl+V). Turn on Edit names, then Add area: click every corner (no limit — 5, 6, 12, …). Click Finish area, the first green point, or press Enter when done. Drag instead for a 4-point rectangle. A new area uses the current alignment. Undo restores the previous overlay or box-edge state. Click Apply alignment after pan/scale or before downloading stamped.pdf. Other on-screen edits do not change the PDF until you Apply.
