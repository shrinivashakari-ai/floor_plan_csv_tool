# floor_plan_csv_tool

Browser-based floor plan zone extractor. Load an input PDF with room names and an output PDF without names, detect zones, match names by relative position, and export the results as CSV.

Open `floor-plan-tools/floor_Plan_cvs.html` in a modern browser. The additional standalone floor-plan tools are also in `floor-plan-tools/`. PDF processing runs locally in the browser using PDF.js; the PDF files are not uploaded to a server.
